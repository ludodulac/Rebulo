# Rebulo — prochaine brique : gate de recherche

Statut : **recherche uniquement**. Ce document n'active aucun pictogramme, ne revendique aucune validation humaine et ne modifie pas le moteur.

## Objectif

Faire avancer la couverture utile sans confondre rendement phonologique et qualité d'un stimulus humain.

Boucle : `couverture réelle → segment manquant à rendement intéressant → candidat lexical concret → risque de dénomination → prototype éventuel → test humain → décision`.

Premiers candidats déjà présents dans les données de recherche : `/ɛ/` → `haie`, `/wa/` → `oie`, `/ɔʁ/` → `or`, `/as/` → `as`. Leurs risques lexicaux documentés restent des hypothèses de recherche, pas des résultats humains.

Avant toute production graphique : relire le rendement courant, vérifier les prototypes existants, préférer le vocabulaire concret et utile, documenter les concurrents lexicaux, puis ne produire un visuel que si le gain attendu justifie un vrai test de dénomination.

La prochaine preuve non automatisable est la première dénomination spontanée sur une révision exacte du stimulus. Tant qu'elle n'existe pas, le statut reste recherche/prototype.
