# Principes UX Rebulo

- Une action principale visible à la fois.
- Boutons courts : verbe ou nom d'action, jamais une phrase.
- Gros contrôles tactiles, utilisables au doigt.
- Le contenu avancé reste replié tant qu'il n'est pas demandé.
- L'image et le résultat priment sur le texte explicatif.
- Les erreurs utilisent des phrases courtes et actionnables.
- Le mode enfant masque les informations professionnelles.
- Toutes les fonctions importantes restent accessibles au clavier.
