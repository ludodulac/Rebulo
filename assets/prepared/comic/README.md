# Rebulo — prepared comic pictograms

This directory stores product-approved visual-direction assets that are prepared for the next library cleanup but are not automatically canonical or clinically validated.

## Visual contract

- clean educational comic/cartoon illustration
- bold dark outlines
- simple saturated colors
- white or transparent background
- one dominant lexical concept
- no word label, number, or caption inside/below the production image
- contextual cue only when it improves lexical salience
