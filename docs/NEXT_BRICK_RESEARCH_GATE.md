# Rebulo — prochaine brique : gate de recherche

Statut : **recherche uniquement**. Ce document n'active aucun pictogramme, ne revendique aucune validation humaine et ne modifie pas le moteur.

## Objectif

Faire avancer la couverture utile sans confondre rendement phonologique et qualité d'un stimulus humain.

Boucle appliquée :

`couverture réelle → segment manquant à rendement intéressant → candidat lexical concret → risque de dénomination → prototype éventuel → test humain → décision`

## Première vague déjà documentée

Les données de recherche existantes proposent notamment :

- `/ɛ/` → `haie` : pictogramme naturel plausible, mais risque `buisson / arbuste / mur végétal` ;
- `/wa/` → `oie` : candidat concret, risque `canard / cygne` ;
- `/ɔʁ/` → `or` : matière représentable, risque `lingot / trésor / métal` ;
- `/as/` → `as` : objet/symbole reconnaissable, risque `carte / carte à jouer`.

Ces appréciations sont des **hypothèses éditoriales/recherche**, pas des résultats de dénomination.

## Ordre de décision

Avant toute production graphique :

1. recalculer/relire le rendement de couverture courant ;
2. vérifier qu'une illustration ou un prototype n'existe pas déjà ;
3. préférer les candidats concrets et fréquents aux formes rares ou flexions ambiguës ;
4. documenter les concurrents lexicaux prévisibles ;
5. ne produire un visuel que si le gain attendu justifie un vrai test de dénomination ;
6. ne jamais activer le candidat sur la seule base d'une image réussie ou d'une CI verte.

## Frontière humaine

La prochaine preuve non automatisable est la **première dénomination spontanée sur une révision exacte du stimulus**. Tant qu'elle n'existe pas, le statut reste recherche/prototype.
