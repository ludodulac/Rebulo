# Rebulo — dépendance des pictogrammes actifs

Ce rapport est généré automatiquement par l’analyse Lexique 4 complète.

Il classe les pictogrammes actifs selon la perte réelle de mots uniques en rébus stricts multi-images si chaque pictogramme devenait indisponible. Ce classement mesure la dépendance du générateur, pas la validité clinique d’un stimulus.
